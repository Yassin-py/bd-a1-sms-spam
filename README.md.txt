# SMS Spam Collection - Big Data Assignment

## Dataset
This project uses the SMS Spam Collection dataset to study normal and spam messages.

## Data Analysis
The analysis includes:
- Dataset inspection and cleaning
- Data transformations
- Spam and normal message comparisons
- Numerical text features
- Correlation heatmap
- Random, stratified, and cluster sampling

## Project Structure
- `data/`: Original and prepared dataset
- `notebook/`: Analysis notebook
- `output/`: Cleaned data, samples, and figures
- `screenshots/`: Evidence of project execution

## How to Run
The project will be built and executed using Docker. The notebook will be accessible through JupyterLab.
